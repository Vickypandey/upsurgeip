# Lawshed React

This folder contains a React layout inspired by the Lawshed landing page. It includes a basic CRA-compatible scaffold and Tailwind configuration.

## Getting started

```bash
npm install
npm start
```

## Structure

- `public/`: static assets and root HTML
- `src/components/`: reusable UI sections
- `src/pages/`: page-level compositions
- `src/App.js`: app shell
- `src/index.js`: entry point
